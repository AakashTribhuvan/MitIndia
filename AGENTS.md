# Project instructions

- Read [`HANDOVER.md`](HANDOVER.md) and [`docs/architecture.md`](docs/architecture.md) before
  changing the prototype.
- This folder is a separate phone-camera prototype. Do not make edits to the original
  `Mudra` repository unless the user explicitly asks.
- Keep the webcam preview local. Do not add frame recording, uploads or persistence unless asked.
- Keep documentation aligned with the actual implementation. Mark device-specific behavior as
  unverified until it has been run on the user's connected phone.
- The immediate milestone is a non-black, responsive Camo Camera feed and visible upper-body
  landmarks. Do not add ISL recognition until this is established.
